# Nifty-paper-trading-bot-
Automated NIFTY 50 paper trading robot using Python. Generates BUY and SELL signals based on 5-minute market data, with virtual capital of ₹5,000, 10-point stop-loss, 15-point target, maximum 2 trades per day, and daily loss limits. Designed for automated paper trading and strategy testing only. No real-money orders.
